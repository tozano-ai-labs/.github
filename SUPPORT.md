# Support

## Comment obtenir de l'aide

- **Questions générales** : utilisez [GitHub Discussions](https://github.com/orgs/tozano-ai-labs/discussions)
- **Bugs** : ouvrez un [Issue](https://github.com/tozano-ai-labs/issues) en utilisant le modèle *Bug report*
- **Propositions de fonctionnalités** : ouvrez un [Issue](https://github.com/orgs/tozano-ai-labs/issues) en utilisant le modèle *Feature request*
- **Problèmes de sécurité** : voir [SECURITY.md](SECURITY.md) pour le signalement privé

## Ressources

- [ai-template](https://github.com/tozano-ai-labs/ai-template) - Documentation commune et règles de travail
- [CONTRIBUTING.md](CONTRIBUTING.md) - Guide de contribution en mode InnerSource
- [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) - Modèle de Pull Request
